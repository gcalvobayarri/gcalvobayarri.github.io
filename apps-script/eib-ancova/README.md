# ANCOVA · autoevaluación EIB

Cuestionario de 5 preguntas: se conservan las preguntas originales 1, 2, 3, 5 y 7, renumeradas del 1 al 5. Incluye las barras de LaTeX corregidas.

## Actualizar sin instalar nada

1. Abre Code.gs en GitHub, pulsa Raw y copia todo.
2. Sustituye todo el contenido de Código.gs en tu proyecto ANCOVA de Apps Script y guarda. Index.html conserva su contenido.
3. Ejecuta repairANCOVAQuestionBank_ desde el selector de funciones. Actualiza la pestaña Preguntas y elimina del banco las preguntas sobrantes. Al cambiar el número de preguntas, conserva las pestañas anteriores de respuestas y resumen con un sufijo histórico y crea pestañas para los nuevos intentos.
4. En Implementar → Gestionar implementaciones, edita la implementación activa, selecciona Nueva versión y pulsa Implementar. Se mantiene el enlace /exec.
5. Recarga el cuestionario: debe mostrar 5 preguntas.

Las preguntas se guardan en Preguntas. Las nuevas entregas se guardan en Respuestas y su resumen en Resumen. GitHub conserva el código y su historial; los cambios se aplican a Google Apps Script siguiendo los pasos anteriores.
